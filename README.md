# AMC 8 · 2026 — Learn by Playing

An interactive, animated solution guide to all 25 problems of the 2026 AMC 8, built for primary-school students.

**Play it here:** https://chun1333.github.io/amc8-2026-learn-by-playing/ — or open `index.html` in any browser (single self-contained page).

## How each problem works
1. **Guess** an answer first (prediction primes attention).
2. **Play** with an interactive picture — every problem has its own widget (sliders, taps, animations).
3. **Climb the steps** — tiny first-principles steps, each unlocked by answering a mini-question.
4. **Dodge the trap** — the most common mistake, explained.
5. **Twin Challenge** — same idea, new numbers, for ★★★ mastery.

## Game layer (research-based)
XP & levels with a buddy that grows (🥚 → 🐉), 3-star mastery, badges, combo streaks, growth-mindset feedback,
spaced "memory checks" on expanding intervals (1 → 3 → 7 → 14 → 30 days), and gentle brain-break nudges.
No loot boxes and no punishing streaks. Progress is saved in the browser (localStorage).
See "Why this works" at the bottom of the home page for the research behind each mechanic.
