# AMC 8 — Learn by Playing

An interactive, animated solution guide to AMC 8 problems (2026, 2025 and 2024 so far; 2023 and 2022 coming), built for primary-school students.

**Play it here:** https://chun1333.github.io/amc8-2026-learn-by-playing/ — or open `index.html` in any browser (single self-contained page).

## How each problem works
1. **Problem**: pick an answer and find out right away if it's right or wrong.
2. **Hint #1 → #4**: one idea at a time, each with a quick tap-check. Behind the scenes the hints build from first principles:
   the math fact you need → a problem-solving tool → the key "aha" → carrying it out. (Kids just see "Hint #1, #2…".)
3. **Play**: an interactive picture for every problem (sliders, taps, animations) to explore freely.
4. **Solution**: press ▶ and the picture plays the full solution step by step, pausing on each question before revealing the answer.
5. **Twin Challenge**: same idea, new numbers, for ★★★ mastery.

## Game layer
XP & levels with a buddy that grows (🥚 → 🐉), 3-star mastery, badges, combo streaks, growth-mindset feedback,
spaced "memory checks" on expanding intervals (1 → 3 → 7 → 14 → 30 days), and gentle brain-break nudges.
No loot boxes and no punishing streaks. Progress is saved in the browser (localStorage).
